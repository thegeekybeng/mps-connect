> [!WARNING]

Postal code sector mapping is an **approximation** — edge cases exist at constituency boundaries. In production, GovTech's boundary API via SingPass registered address is the authoritative source.

---

## How to Read This Document

- **GRC** = Group Representation Constituency (4–5 MPs, each with a division/ward)
- **SMC** = Single Member Constituency (1 MP, 1 ward)
- **Division** = The ward within a GRC that a specific MP serves
- **Postal Sectors** = The first 2 digits of a Singapore 6-digit postal code

## How to Update the Data

### Correcting an MP-to-Division Assignment

If you have verified information that an MP serves a different division than listed above, update the DB directly:

```sql
-- Example: Correct Nadia Ahmad Samdin's division from Cheng San to something else
UPDATE constituencies
SET division = 'Correct Division Name'
WHERE mp_name = 'Nadia Ahmad Samdin'
  AND name = 'Ang Mo Kio GRC';
```

### Correcting a Postal Sector Mapping

If a postal sector is mapped to the wrong constituency:

```sql
-- Step 1: Find the correct constituency ID
SELECT id, name, division, mp_name FROM constituencies
WHERE division = 'Correct Division Name';

-- Step 2: Update the mapping
UPDATE postal_sector_map
SET constituency_id = <correct_id>,
    notes = 'Corrected: was mapped to X, should be Y'
WHERE sector_prefix = '31';
```

If you have a complete verified dataset and want to replace everything:



### Verifying After Changes

```bash
# Count total MPs (should be 97)
docker exec mps-postgres psql -U mps -d mps_connect -c "SELECT COUNT(*) FROM constituencies;"

# Check party breakdown
docker exec mps-postgres psql -U mps -d mps_connect -c "SELECT party, type, COUNT(*) FROM constituencies GROUP BY party, type ORDER BY type, party;"

# Check postal mapping for a specific sector
docker exec mps-postgres psql -U mps -d mps_connect -c "
SELECT p.sector_prefix, c.name, c.division, c.mp_name
FROM postal_sector_map p
JOIN constituencies c ON c.id = p.constituency_id
WHERE p.sector_prefix = '31';
"

# Export current data to CSV for review
docker exec mps-postgres psql -U mps -d mps_connect -c "
COPY (SELECT id, name, division, mp_name, party, type FROM constituencies ORDER BY name, division)
TO STDOUT WITH CSV HEADER;
" > ./docs/constituencies_export.csv
```

### Schema Reference

```sql
-- constituencies table
CREATE TABLE constituencies (
  id              SERIAL PRIMARY KEY,
  name            VARCHAR(100) NOT NULL,   -- e.g. "Jalan Besar GRC"
  division        VARCHAR(100),            -- e.g. "Whampoa"
  mp_name         VARCHAR(100),            -- e.g. "Shawn Loh"
  party           VARCHAR(10),             -- "PAP" or "WP"
  type            VARCHAR(5),              -- "GRC" or "SMC"
  branch_location TEXT,                    -- MPS office address (optional)
  mps_schedule    VARCHAR(100),            -- e.g. "Every Wednesday, 8.00 PM"
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- postal_sector_map table
CREATE TABLE postal_sector_map (
  sector_prefix   CHAR(2) PRIMARY KEY,     -- first 2 digits of postal code
  constituency_id INT NOT NULL REFERENCES constituencies(id),
  notes           TEXT                      -- human-readable area description
);
```
